#  Retail Pricing & Catalog Engine

### Project Overview
This project is a Spring Boot-based backend application that simulates a retail pricing system. It manages product catalog data and calculates final pricing using business rules like GST, discounts, and promotional offers.

### Tech Stack
- Java (JDK 21)
- Spring Boot
- REST APIs
- MySQL (optional)
- Postman (API testing)

### Features
- Product CRUD operations
- Pricing engine with GST (18%)
- Discount and promotional logic (Buy 1 Get 1, seasonal offers)
- RESTful API architecture

### APIs
- GET /price
- POST /products
- GET /products
